# Нормоконтролёр

Проверка и исправление оформления Word-документов (.docx) по ГОСТ: ВКР, курсовые, рефераты, отчёты о НИР.

Загружаете документ — получаете отчёт о нарушениях и исправленный файл. Текст работы не меняется, правится только оформление.

> Проект в разработке. Работают проверка, механические исправления в режиме рецензирования и рендер в PDF; значения профиля ещё нужно сверить с текстами стандартов (`TODO: сверить`).

## Быстрый старт

```
pip install -r requirements.txt
python3 scripts/audit.py работа.docx                          # отчёт о нарушениях
python3 scripts/fix_layout.py работа.docx -o out/работа_nk.docx  # исправления в режиме рецензирования
python3 scripts/audit.py out/работа_nk.docx                   # что осталось
ACCEPT=1 scripts/render_check.sh out/работа_nk.docx out        # PDF и PNG страниц
```

## Как пользоваться агентом

- **Claude Code** — откройте репозиторий, приложите .docx и напишите «проверь оформление по ГОСТ». Скилл `.claude/skills/normokontrol/` подключится сам.
- **claude.ai** — соберите скилл `scripts/build_skill.sh`, загрузите `out/normokontrol-skill.zip` в «Настройки → Возможности → Навыки» и присылайте .docx в чат.

Агент сначала показывает список нарушений, потом исправляет механику скриптом, смысловое оформление (подписи, заголовки, библиографию) правит сам и отдаёт файл с видимыми правками и отчёт: что исправлено, что осталось на автора.

## Что проверяется

- Поля, размер бумаги, шрифт, кегль, межстрочный интервал, абзацный отступ, выравнивание.
- Нумерация страниц.
- Заголовки структурных элементов и разделов.
- Подписи рисунков и таблиц.
- Нумерация формул.
- Список использованных источников (ГОСТ Р 7.0.100-2018).

## Как устроено

Механические правила (поля, шрифты, интервалы) применяет скрипт на Python: одинаково и предсказуемо каждый раз. Смысловые правки (библиография, подписи, структура) делает Claude по правилам из скилла `.claude/skills/normokontrol/`.

Правила лежат в профилях `profiles/*.yaml`. Базовый профиль — ГОСТ 7.32-2017. Методичка вуза оформляется отдельным профилем поверх базового: при проверке она важнее ГОСТа.

## Структура

```
profiles/      профили оформления: ГОСТ и методички вузов
scripts/       проверка и исправление .docx
references/    выжимки правил со ссылками на пункты стандартов
tests/samples/ документы для проверки
.claude/skills/normokontrol/  скилл для Claude Code и claude.ai
```

## Стандарты

- ГОСТ 7.32-2017 «Отчёт о научно-исследовательской работе. Структура и правила оформления».
- ГОСТ Р 7.0.100-2018 «Библиографическая запись. Библиографическое описание».
- ГОСТ Р 7.0.5-2008 «Библиографическая ссылка».
- ГОСТ 2.105-2019 «ЕСКД. Общие требования к текстовым документам» (заменил ГОСТ 2.105-95) — для технических работ, если этого требует методичка. Профиль пока не создан, см. `references/eskd.md`.

Тексты стандартов в репозиторий не входят: здесь только собственные выжимки правил со ссылками на пункты.

## Добавить свой вуз

Скопируйте `profiles/gost-7.32-2017.yaml`, поменяйте значения по методичке и пришлите pull request. Подробнее — в `profiles/README.md`.
