# Нормоконтролёр

Проверка и исправление оформления Word-документов (.docx) по ГОСТ: отчёты о НИР, ВКР, курсовые, рефераты, диссертации и авторефераты.

Загружаете документ — получаете отчёт о нарушениях и исправленный файл. Текст работы не меняется, правится только оформление.

> Проект в разработке. Работают проверка, механические исправления в режиме рецензирования и рендер в PDF; значения профилей сверены с текстами ГОСТ 7.32-2017, ГОСТ Р 7.0.11-2011, ГОСТ Р 7.0.5-2008 и ГОСТ Р 2.105-2019; образцы библиографических записей по ГОСТ Р 7.0.100-2018 ещё нужно сверить (`TODO: сверить` в `references/bibliography.md`).

## Быстрый старт

```
pip install -r requirements.txt
python3 scripts/audit.py работа.docx                          # отчёт о нарушениях
python3 scripts/fix_layout.py работа.docx -o out/работа_nk.docx  # исправления в режиме рецензирования
python3 scripts/audit.py out/работа_nk.docx                   # что осталось
ACCEPT=1 scripts/render_check.sh out/работа_nk.docx out        # PDF и PNG страниц
```

## Как пользоваться агентом

- **Claude Code** — откройте репозиторий, приложите .docx и напишите «проверь оформление по ГОСТ». Скилл `.claude/skills/normokontrol/` подключится сам.
- **claude.ai** — соберите скилл `scripts/build_skill.sh`, загрузите `out/normokontrol-skill.zip` в «Настройки → Возможности → Навыки» и присылайте .docx в чат.

Агент сначала показывает список нарушений, потом исправляет механику скриптом, смысловое оформление (подписи, заголовки, библиографию) правит сам и отдаёт файл с видимыми правками и отчёт: что исправлено, что осталось на автора.

## Что проверяется

- Поля, размер бумаги, шрифт, кегль, межстрочный интервал, абзацный отступ, выравнивание.
- Нумерация страниц.
- Заголовки структурных элементов и разделов.
- Подписи рисунков и таблиц.
- Нумерация формул.
- Список использованных источников (ГОСТ Р 7.0.100-2018).

## Как устроено

Механические правила (поля, шрифты, интервалы) применяет скрипт на Python: одинаково и предсказуемо каждый раз. Смысловые правки (библиография, подписи, структура) делает Claude по правилам из скилла `.claude/skills/normokontrol/`.

Правила лежат в профилях `profiles/*.yaml`: по профилю на тип документа и стандарт. Методичка вуза или требования совета оформляются отдельным профилем поверх базового: при проверке они важнее ГОСТа.

## Структура

```
profiles/      профили оформления: ГОСТ и методички вузов
scripts/       проверка и исправление .docx
references/    выжимки правил со ссылками на пункты стандартов
tests/samples/ документы для проверки
.claude/skills/normokontrol/  скилл для Claude Code и claude.ai
```

## Какие документы оформляем

Агент начинает с вопроса, что нужно оформить: разные ГОСТы регулируют разные документы.

| Документ | Основной стандарт | Профиль | Готовность |
|---|---|---|---|
| Отчёт о НИР | ГОСТ 7.32-2017 | `gost-7.32-2017` | готово |
| ВКР, курсовая, реферат, отчёт о практике | отдельного ГОСТа нет; вузы опираются на ГОСТ 7.32-2017, главнее методичка | `student-work-gost-7.32-2017` | готово |
| Диссертация (рукопись) | ГОСТ Р 7.0.11-2011, разделы 4–5 | `gost-r-7.0.11-2011-dissertation` | бета |
| Автореферат | ГОСТ Р 7.0.11-2011, разделы 8–9 | `gost-r-7.0.11-2011-autoreferat` | частично: ГОСТ задаёт только структуру |
| Пояснительная записка, техдокументация | ГОСТ Р 2.105-2019 (ЕСКД) | — | не поддерживается |

Во всех профилях список литературы проверяется по ГОСТ Р 7.0.100-2018, ссылки в тексте — по ГОСТ Р 7.0.5-2008. Актуальное меню: `python3 scripts/catalog.py`.

## Стандарты и их актуальность

Статус проверен 19.10.2026 по реестру Росстандарта и справочным системам. Таблицу с датами печатает `python3 scripts/catalog.py --standards`; источник — `profiles/catalog.yaml`.

| Стандарт | Для чего | Статус |
|---|---|---|
| ГОСТ 7.32-2017 | отчёт о НИР; основа методичек для учебных работ | действует с 01.07.2018, с поправками 2019–2022; заменил ГОСТ 7.32-2001 |
| ГОСТ Р 7.0.11-2011 | диссертация и автореферат | действует с 01.09.2012 |
| ГОСТ Р 7.0.100-2018 | библиографическое описание в списке литературы | действует с 01.07.2019; в РФ заменил ГОСТ 7.1-2003 |
| ГОСТ Р 7.0.5-2008 | библиографические ссылки в тексте | действует с 01.01.2009 |
| ГОСТ Р 2.105-2019 | ЕСКД, текстовые документы; на него ссылаются ГОСТ 7.32 и 7.0.11 в части рисунков, таблиц, формул | действует с 01.02.2020, Изменение № 1 с 01.02.2021; в РФ заменил ГОСТ 2.105-95 |
| Постановление Правительства РФ № 842 | порядок присуждения учёных степеней | действует, часто меняется; оформление файла не регулирует |

Старые стандарты внутри действующих (например, ГОСТ Р 7.0.11-2011 ссылается на ГОСТ 7.1-2003 и ГОСТ 2.105-95) применяются в заменяющей редакции — так требуют сами стандарты в разделе «Нормативные ссылки».

Тексты стандартов в репозиторий не входят: здесь только собственные выжимки правил со ссылками на пункты (`references/`).
