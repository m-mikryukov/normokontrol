# Скрипты

- `catalog.py` — что оформляем: типы документов, профили, стандарты и их статус (`--standards`), проверка каталога (`--check`).
- `audit.py` — отчёт о нарушениях по профилю (Markdown, `--json` для машинной обработки). Документ не меняет.
- `fix_layout.py` — механические исправления: формат и поля, шрифт, кегль, цвет, интервал, отступы, выравнивание, заголовки, подписи, номера страниц. Всё в режиме рецензирования (`--no-track` — без него).
- `pdf_audit.py` — проверка по готовому PDF: формат, поля по границе текста, кегль, интервал, номер страницы, структура, подписи, ссылки, список литературы. Только отчёт — PDF не правится.
- `accept_changes.py` — копия с принятыми правками, чтобы посмотреть итоговый вид.
- `render_check.sh` — .docx → PDF и PNG страниц через LibreOffice (`ACCEPT=1` — с принятыми правками).
- `build_skill.sh` — сборка самодостаточного скилла для claude.ai.
- `nk_common.py`, `nk_tracked.py` — общая библиотека: профили, роли абзацев, эффективное оформление, рецензирование.

Каждое нарушение в отчёте помечено, кто исправляет: `авто` (скрипт), `Claude` (смысловое оформление по скиллу), `автор` (содержание).

Зависимости: `pip install -r requirements.txt`. Тесты: `pip install pytest && python3 -m pytest tests`.
