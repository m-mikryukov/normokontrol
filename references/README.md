# Выжимки правил

Здесь лежат собственные краткие формулировки правил со ссылкой на пункт стандарта. Тексты ГОСТов целиком не копируем: на них есть права у Росстандарта.

- `gost-7.32-2017.md` — отчёт о НИР и основа учебных работ.
- `gost-r-7.0.11-2011.md` — диссертация и автореферат, отличия от ГОСТ 7.32, Постановление № 842.
- `bibliography.md` — описание источников по ГОСТ Р 7.0.100-2018, с образцами.
- `gost-r-7.0.5-2008.md` — библиографические ссылки в тексте.
- `eskd.md` — ГОСТ Р 2.105-2019 (ЕСКД) для технических работ.

Статус стандартов и дата проверки — в `profiles/catalog.yaml`.

Формат записи:

```
## Поля страницы
Источник: ГОСТ 7.32-2017, п. …
Правило: …
```

Номера пунктов, не сверенные с официальным текстом, помечены `TODO: сверить`.
