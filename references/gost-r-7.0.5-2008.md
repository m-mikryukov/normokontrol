# ГОСТ Р 7.0.5-2008: библиографическая ссылка

Собственная выжимка. Пункты сверены с текстом стандарта (переиздание 2020 г.) 19.10.2026. Стандарт действует с 01.01.2009, не заменён.

## Виды ссылок
Источник: ГОСТ Р 7.0.5-2008, п. 4.6; разделы 5–7.
Правило: внутритекстовые (в круглых скобках прямо в тексте), подстрочные (в сноске внизу страницы) и затекстовые (после текста, связь с текстом через номер). ГОСТ 7.32-2017 (п. 6.9.1) для отчётов предписывает затекстовые ссылки с номером в квадратных скобках.

## Затекстовые ссылки
Источник: п. 7.4–7.4.2.
Правило: нумерация сплошная по всему тексту или по главам. Номер записи — в квадратных скобках в строку с текстом: [59]. Ссылка на фрагмент — номер и страница через запятую: [10, с. 81].

## Несколько источников в одной ссылке
Источник: п. 4.8, 9.1.
Правило: несколько объектов объединяют в одну комплексную ссылку; ссылки внутри неё разделяют точкой с запятой с пробелами: [3; 7]. Запись через запятую ([3, 7]) встречается в методичках; если методичка требует так — следуем методичке.

## Повторные ссылки
Источник: раздел 8.
Правило: повторную ссылку дают в сокращённой форме, если в первичной есть все сведения; приём сокращения — единый для документа. В подстрочных ссылках при повторе подряд — «Там же».

## Что проверяет инструмент
- `audit.py` находит ссылки вида [N], [N, с. M], [N–M] и сверяет номера с количеством записей в списке, ищет записи без ссылок и проверяет порядок первого упоминания (если профиль требует).
- Разделитель внутри скобок не исправляется автоматически: Claude предлагает правку автору.
