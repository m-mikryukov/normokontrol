# Профили оформления

Профиль — набор значений для проверки и исправления документа.

- `gost-7.32-2017.yaml` — базовый профиль по ГОСТ 7.32-2017.

## Профиль вуза

Методичка вуза почти всегда отличается от ГОСТа в мелочах: кегль, поля, титульный лист. Профиль вуза наследует базовый и переопределяет только отличия:

```yaml
name: Методичка <вуз>, <год>
id: <vuz>-<год>
extends: gost-7.32-2017

text:
  size_pt_min: 14
```

Название файла: `<вуз>-<факультет или тип работы>-<год>.yaml`. В pull request приложите ссылку на методичку.
